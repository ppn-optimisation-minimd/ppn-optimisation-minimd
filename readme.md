# Optimisation de MiniMD à l'aide de MAQAO

### Motivations

Comparer les qualités d'optimisation d'un humain et d'un LLM.

### Mise en oeuvre

L'outil de mesure de performance est MAQAO. <br>
Des mesures seront effectuées sur MiniMD sans modifications afin d'obtenir des mesures étalons. Ces mesures seront comparées avec des mesures effectuées sur les codes optimisés par un LLM d'une part, et par des humains d'autre part.
